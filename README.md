# Projetos da Faculdade

Este repositorio reúne vários scripts dos códigos cujo vim montando ao longo de minha jornada como estudante universitário. Há outras coisas em outros repo também!
Começou com reatores que montei e umas coisas de ML a parte (quem sabe no futuro os dois..)

## Requisitos

- Python 3.10 ou superior
- NumPy
- SciPy
- Matplotlib
- Pandas
- Scikit

Instalação das dependencias:

```bash
pip install numpy matplotlib pandas scipy scikit-learn
```

## Como executar

Cada arquivo pode ser executado diretamente. 
Use algo como Google Colab ou Visual Studio Code para facilitar a sua vida!

Os scripts imprimem resultados numéricos no terminal e, em geral, exibem gráficos com Matplotlib.
